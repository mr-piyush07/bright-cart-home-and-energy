# Bright Cart Home And Energy

Build a modern multi-category e-commerce website frontend based on the attached functional requirements and image assets checklist.

- Color palette: Apply the attached 60-30-10 palette (60% white dominant background, 30% dark charcoal structure/text, 10% vibrant orange accent for CTAs, badges, and sale highlights).
- Categories: Detergent Powder, Floor Cleaner, Water Pumps, and Solar Panels.
- Architecture: Frontend only. In place of a real backend, create static data stores and mock API service files that realistically simulate backend endpoints (products, categories, filtering, search, cart, wishlist, and simulated checkout).
- UX: Smooth page transitions, responsive carousels/sliders, modern product cards, quick view, and clean product details.
